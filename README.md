my mods for lucid blocks (mostly using the Qualia-Mods API)  

# Mods

- [Spawner+](#Spawner+)
- [Apotheon](#Apotheon)
- [CMDS](#CMDS)
- [NoFog](#NoFog)

## Air Strafe - [download](https://github.com/rekitrelt/Lucid-Blocks-Mods/releases/download/Lucid_Blocks_Mods/AirStrafing.zip) - adds Air-Strafing (like CS:GO or Quake)

Adds customizable air strafing movement.

## Spawner+ - [download](https://github.com/rekitrelt/Lucid-Blocks-Mods/releases/download/Lucid_Blocks_Mods/Spawner+.zip) - improvements to vermin vigil blocks (spawners)

Adds additional spawning controls.

## Apotheon - [download](https://github.com/rekitrelt/Lucid-Blocks-Mods/releases/download/Lucid_Blocks_Mods/Apotheon.zip) - improvements to apotheosis/fusion (crafting)

Adds crafting and fusion improvements.

## CMDS - [download](https://github.com/rekitrelt/Lucid-Blocks-Mods/releases/download/Lucid_Blocks_Mods/CMDS.zip) - adds a command console (open with `/~` or `;`)

Adds crafting and fusion improvements.

## NoFog - [download](https://github.com/rekitrelt/Lucid-Blocks-Mods/releases/download/Lucid_Blocks_Mods/NoFog.zip) - removes fog

Adds crafting and fusion improvements.
